# ACT 4: THE SPAM FRAMEWORK
*1.5 minutes*

---

**HEDGE:** 🦔
> Here's how you message without being sleazy: **SPAM**

```
S = SEGMENT  (Who are they?)
P = PERSONA  (Who are you talking to?)
A = ANGLE    (What's your argument?)
M = MESSAGE  (The actual words)
```

**PIPPA:** 🐧
> I'm using Mixpanel + LaunchDarkly + FullStory.
> Paying $3K/month. They don't even talk to each other.

**DATA:** 🦉
> Segment: Multi-Tool Analytics User
> Pain: Tool sprawl, data silos, high costs

**HEDGE:** 🦔
> Now watch the difference in messaging:

---

### ❌ SPIKE'S WAY (Assumptive):

```
Subject: You're wasting money

Pippa,

I saw you're using Mixpanel, LaunchDarkly, AND FullStory.

You're definitely overpaying. PostHog cuts costs by 60%.

Let's chat this week?
```

**PIPPA:** 🐧
> DELETE. You don't know me.

---

### ✅ HEDGE'S WAY (Unassumptive):

```
Subject: Spotted your tech stack - possibly relevant?

Hey Pippa,

I noticed you might be running Mixpanel + LaunchDarkly + FullStory
(based on BuiltWith data, apologies if outdated).

Not sure if this is a pain point for you, but I've seen teams with
similar setups hit two issues:
1. Data scattered across platforms
2. Paying 3-5x for an integrated solution

I put together a quick breakdown. Thought it might be useful,
even if you're happy with your current setup.

Here's the doc: [link]

No worries if not relevant. If questions, I'm around.
```

**PIPPA:** 🐧
> Okay, this is actually helpful.
> You're not telling me what I need. You're OFFERING value.
>
> I'll click that link.

**DATA:** 🦉
> Key difference: "Not sure..." "Possibly..." "Might be..."
>
> You have 3rd party data, not mind-reading powers.
> Always qualify. Never assume.

---

   No pressure at all."

**HEDGE:** 🦔

> We don't need to convince you. We need to be AVAILABLE when you're ready.
>
> Forcing a bad-fit deal gets you:
> - Quick churn
> - Bad word-of-mouth
> - Damaged brand
>
> Not worth it.

**PIPPA:** 🐧
> That's refreshingly honest.
>
> You know what? I'm gonna try PostHog this afternoon.
> Not because you pushed me. Because you DIDN'T.

# ACT 6: THE PRINCIPLES
*1 minute*

---

**HEDGE:** 🦔
> Tools will change. Tactics will evolve.
> But the PRINCIPLES stay the same:

---

## THE 5 POSTHOG OUTBOUND PRINCIPLES

### 1. VALUE BEFORE EXTRACTION
```
Give before you ask
Make it useful, not a veiled pitch
```

### 2. UNASSUMPTIVE TONE
```
You have data, not mind-reading powers
"Not sure..." "Possibly..." "Is this...?"
```

### 3. HONEST OVER CLEVER
```
Acknowledge when you're not a fit
Respect "no" without handling it
```

### 4. SHIP EXPERIMENTS, NOT GUESSES
```
Test angles. Measure. Iterate.
Treat outbound like product development
```

### 5. PROTECT THE BRAND ABOVE ALL
```
Every message = PostHog's reputation
When in doubt, choose respect
```
